## Descripción

Desarrollar una base de datos relacional para una plataforma de reserva y alquiler de diferentes tipos de vehículos presentes en varias ciudades del país. La plataforma cuenta con diferentes tipos de usuarios (desde ocasionales hasta empresariales) y también precios y membresías para los diferentes vehículos.

## Objetivo del Proyecto

Diseñar y desarrollar una base de datos que soporte la operación de la plataforma (reservas alquileres usuarios precios y membresías) garantizando la consistencia de la información a través de las distintas ciudades donde opera.

## Conceptos Clave

* Desacoplamiento del Inventario (Catálogo vs. Activo Físico).
* Cálculo de Disponibilidad Dinámica (Time-Series Overlap).
* Independencia Transaccional y Financiera.
* Segmentación B2B y B2C (Multi-tenant lógico).
* Ciclo de Vida de Estados Finitos.
